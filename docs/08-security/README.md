# セキュリティ

## 覚えるポイント

- 必要最小限の権限を与える
- `sudo`は許可された管理操作を実行する仕組み
- SUID、SGID、sticky bitの意味
- 不要なサービスや待受ポートを減らす

## コマンド例

```bash
id
sudo -l
find /usr/bin -perm -4000 -type f 2>/dev/null
ls -ld /tmp
ss -tuln
```

## 特殊権限

- SUID: 実行ファイルの所有者権限で実行
- SGID: 実行時のグループ、またはディレクトリ内のグループ継承
- sticky bit: 共有ディレクトリで他人のファイル削除を制限

権限変更は影響範囲を確認し、実習用ファイルだけで行います。
