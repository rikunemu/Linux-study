# 重要ポイント

## 混同しやすい組み合わせ

- `df`: ファイルシステム単位の空き容量 / `du`: ファイル・ディレクトリ単位の使用量
- `find`: パスや属性でファイルを検索 / `grep`: 内容を検索
- ハードリンク: inodeを共有 / シンボリックリンク: パスを参照
- `>`: 上書き / `>>`: 追記
- `2>`: 標準エラー出力 / `>`: 標準出力
- PID: プロセスID / PPID: 親プロセスID
- `/etc/passwd`: アカウント情報 / `/etc/shadow`: パスワード関連情報

## 復習方法

1. 意味を見ずに説明する
2. devcontainerで小さな例を作る
3. 出力を予想してから実行する
4. 間違いを[mistakes.md](mistakes.md)へ記録する
