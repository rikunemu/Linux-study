# 重要コマンド一覧

| 目的 | コマンド |
| --- | --- |
| ファイル一覧 | `ls` |
| ファイル検索 | `find`, `locate` |
| 内容検索 | `grep` |
| テキスト加工 | `cut`, `sort`, `uniq`, `tr`, `sed` |
| 権限変更 | `chmod`, `chown`, `chgrp` |
| 容量確認 | `df`, `du` |
| マウント確認 | `findmnt`, `mount` |
| プロセス確認 | `ps`, `top`, `pgrep` |
| プロセス制御 | `kill`, `nice`, `renice` |
| ユーザー確認 | `id`, `getent`, `who` |
| ネットワーク | `ip`, `ss`, `ping`, `getent hosts` |
| ログ | `journalctl` |

各コマンドについて「用途」「主要オプション」「実行例」「結果」を説明できる状態を目指します。
